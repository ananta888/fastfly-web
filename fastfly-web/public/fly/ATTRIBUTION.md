# Fly body assets — provenance & license

The mesh files in `stl/`, the body/joint hierarchy in `fly-rig.json`, and the
baked per-leg joint-angle trajectories in `gait-tables.json` are derived from
the **NeuroMechFly v2** biomechanical model, generated by the
[flygym](https://github.com/NeLy-EPFL/flygym) project (Neuroengineering
Laboratory, EPFL — Pavan Ramdya et al.), **Apache License 2.0**.

Specifically, sourced from `NeLy-EPFL/flygym`, `gh-pages` branch,
`wasm/game/assets/`:

- `stl/*.stl` — the flattened, decimated collision/visual meshes from
  `wasm/game/assets/model/*.stl` (originally derived from a micro-CT scan of
  an adult female fly; see the NeuroMechFly v2 publication,
  https://neuromechfly.org/).
- `fly-rig.json` — hand-extracted from `wasm/game/assets/model/fly.xml` (a
  flattened MJCF): body names, relative positions/orientations, per-leg joint
  axes, and per-joint `springref` (used here as the fixed neutral pose for
  the four unactuated tarsus segments per leg). Material colors are read from
  the same file's flat-rgba `<material>` definitions (`wing`, `eye`,
  `arista`, `haltere`) plus the average color of each part's texture
  definition for the rest (headthorax/antennaproboscis/abdomen/coxa/
  trochanterfemur/tibia/tarsus — flygym renders these as procedural
  textures we don't reproduce, only their base tone).
- `gait-tables.json` — trimmed from `wasm/game/assets/model_meta.json`'s
  `preprogrammed.legs` (a 360-sample, 7-DOF-per-leg joint-angle table baked
  from flygym's `PreprogrammedSteps`, itself derived from real recorded
  Drosophila walking kinematics via
  [DeepFly3D](https://github.com/NeLy-EPFL/DeepFly3D)) plus `control.leg_order`
  / `control.tripod_map`.

None of MuJoCo, MuJoCo-WASM, or flygym's own physics/control code is used
here — FastFly poses this rig kinematically in three.js, driven by FastFly's
own simulated-brain motor signals (`descending_center/left/right`), not by
flygym's CPG/keyboard controller. Only the body geometry and the real
recorded gait *shape* (joint angle vs. phase) are reused.

Please retain this file and cite the NeuroMechFly v2 publication
(https://neuromechfly.org/) if these assets are reused elsewhere.
